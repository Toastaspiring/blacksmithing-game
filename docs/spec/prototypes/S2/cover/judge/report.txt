===== modelChoice

- A Ball's octahedron lies on the world axes.

- Probe piece: n_q·x ≤ d_q + sag_q + EPS − (HIDE_OFFSET + sag_f)·(n_q·n_f).

===== capProposal
VERDICT_WORK_MAX = 500,000 Cover work units per exposure call, in Balance.Geometry (a §16 row). Units are counted the way A counts them today, for now: 1 unit = 2 vertex-against-line tests, plus 4 per model facet. They are summed over all parts' verdicts in part order. Each part's units depend only on that part and its hiders, so the total, and whether it exceeds the cap, do not depend on order.

Mechanism:
- Cover.shown takes the remaining budget and returns (shown, work, over), stopping between polygons once its work passes the budget.
- Sampling.exposure subtracts each part's work. When the budget runs out it returns at once with capped = true and no kept row.
- Analyze stage 3: if exposure.capped, return validation { ok = false, errors = { {code = "TooComplex"} } } with no partId, and measure nothing (measureInvalid cannot apply: no verdict exists).
- Save stores the design as invalid. The editor (S6) shows "too complex to analyse" with no part highlighted. E_INVALID_BLUEPRINT carries the detail code TooComplex.
- No verdict is ever changed by the cap, so hidden parts can only make their own design visibly invalid. That keeps the hidden-part channel closed.

Time at the cap (quiet Lune):
