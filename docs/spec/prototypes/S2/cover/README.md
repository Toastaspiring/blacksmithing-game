# S2 — the exact verdict (E-S2.12)

Evidence, not game code: the scripts and data behind SPEC §4.4's verdict on a polyhedral model, its conservative probe and
`VERDICT_WORK_MAX` (§4.9, §17.2), and the designs T-PERF-01 and S-PERF-01 run. Lune 0.8.9. The scripts ran from scratch
folders beside copies of the repo, and their relative requires assume that layout (`../snap/…` the build with the cap
lifted, `../snapcap/…` the build, `../old/…` the tree before, with the line reading; `./repo/…` in the judge's): to run one
again, put it beside such copies. Some data sets are read by absolute path from the session's scratch folders (`build/lib.luau`'s
and `judge/jsets.luau`'s `SCR`) and are not in the repo: the 1,340-design attack corpus (`m2x-protoA/out/corpus_all.jsonl`),
the climbs of A, B and the judge, and the verifiers' 12 families (`m2x-protoB/b_sets.luau`); only the 17 attack designs of
`tests/Physics/CoverAttacks.luau` and `worst_designs.luau` are kept here. The scripts in `fix/` require the repo itself by
absolute path (`fix/lab.luau`'s `LAB_ROOT`, by default the repo; a copy of the tree before for comparisons) and run from the
repo's root.
